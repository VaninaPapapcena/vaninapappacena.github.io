# GitHub Pages portfolio

This folder contains a simple one-page portfolio that can replace the current Framer site with a low-cost static site.

## Files
- `index.html` — main page
- `styles.css` — styles

## Recommended publishing path
The simplest option is to create a GitHub repository named:

`<your-github-username>.github.io`

Then upload these files to the root of that repository.

## How to publish
1. Create a new public repository on GitHub named `<your-github-username>.github.io`.
2. Upload `index.html` and `styles.css`.
3. Commit the files to the `main` branch.
4. Open the repository settings on GitHub.
5. Go to **Pages**.
6. Confirm deployment from the `main` branch / root.
7. Your site will be published at `https://<your-github-username>.github.io/`.

## Custom domain later
If you want to reuse `vaninapappacena.com`, you can connect the custom domain later from GitHub Pages settings.

## Before publishing
- Replace the LinkedIn placeholder in `index.html`.
- Adjust any copy you want to personalize.
- If you want a downloadable CV or PDF portfolio, add the file to this folder and link it from the page.
